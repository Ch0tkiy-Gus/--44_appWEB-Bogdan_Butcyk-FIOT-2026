Shape of Dreams

From Wikipedia, the free encyclopedia

Shape of Dreams

A rare Grade-IV "Aeon Dream Shard", a core gameplay artifact.

Developer Somnum Interactive
Publisher Etheric Publishing
Genre Action Roguelike RPG

Shape of Dreams is an upcoming procedural action role-playing video game centered around dream manipulation, surreal dimension traversal, and tactical item modification. Set in the infinite stellar ether of the Dreamscape, players assume the role of The Dreamer, navigating subconscious layers to recover shattered memories while preventing the spread of deep-seated nightmares.

The game features a unique mechanics system driven by Dream Shards—mystical crystalline artifacts that represent concentrated subconscious thoughts. These artifacts modify player attributes, grant temporary elemental abilities, and serve as the core currency for unlocking persistent upgrades.

Gameplay Mechanics

Traversal across subconscious levels is facilitated by a system of procedural thresholds. Each player must balance their cognitive stability with their progression speed. If stability reaches zero, the current dream collapses, returning the player to the Waking Citadel with a portion of accumulated materials.

Key features include:

  • Dynamic Dream Layers: Multi-level dungeons that shift attributes according to player choices.
  • Chronostasis Manipulation: Ability to temporarily slow nightmares using Lucid Core energy.
  • Subconscious Forge: Crafting station used to synthesize higher-tier dream tools and keys.

Dream Shards & Artifacts

Throughout the journey, players discover varying grades of shards, outlined in the primary catalog below:

Artifact Name Primary Class Stability Mod In-game Utility Description
Lucid Fragment Common +10% Basic cognitive reinforcement; stabilizes active dream portals.
Aeon Shard Rare +25% Grants chronostasis abilities; slows nightmare acceleration rates.
Shattered Core Legendary +50% Unlocks ultimate subconscious forge tiers; allows tier synthesis.

Core Gameplay Loop

  1. Incubation The Player logs in and selects a dream seed in the Waking Citadel.
  2. Descent Traversal into subconscious rooms, engaging in procedural real-time combat.
  3. Assimilation Uncovering shattered memory nodes and collecting dream shard materials.
  4. Resolution Either escaping successfully via portal or collapsing back to the citadel base.
